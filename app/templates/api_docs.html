Base API Endpoint: http://127.0.0.1:5000/api/v1
Probe Health API

Example cURL Request:
curl http://127.0.0.1:5000/api/v1/health
Expected Response (HTTP 200 OK):
{
  "active_models": {
    "blood_ocr": true,
    "crop_screening": true,
    "plant_pathology": true,
    "skin_screening": true,
    "symptoms_triage": true,
    "xray_analysis": true
  },
  "api_version": "1.0.0",
  "status": "healthy"
}

JSON Payload Body:
{
  "symptoms": ["fever", "cough", "headache"],
  "temperature": 101.5,
  "temperature_unit": "F",
  "age": 28,
  "duration": "days",
  "severity": "moderate",
  "allergies": ["penicillin"]
}
Example cURL:
curl -X POST http://127.0.0.1:5000/api/v1/triage/symptoms \
  -H "Content-Type: application/json" \
  -d '{"symptoms": ["fever", "cough"], "temperature": 101.5, "age": 30}'
Response Structure:
{
  "module": "symptoms_triage",
  "status": "success",
  "triage_result": {
    "is_emergency": false,
    "primary_syndrome": "Upper Respiratory Tract Infection",
    "urgency_level": "MODERATE",
    "red_flags": []
  }
}

Example Request:
curl "http://127.0.0.1:5000/api/v1/medicines?query=paracetamol"

Python Client Example

import requests

BASE_URL = "http://127.0.0.1:5000/api/v1"

# 1. Triage Symptoms via API
triage_payload = {
    "symptoms": ["fever", "cough", "shortness_of_breath"],
    "temperature": 102.5,
    "age": 35
}
res = requests.post(f"{BASE_URL}/triage/symptoms", json=triage_payload)
print("Triage Response:", res.json())

# 2. Query Drug Precautions
med_res = requests.get(f"{BASE_URL}/medicines", params={"query": "cetirizine"})
print("Pharmacopeia:", med_res.json())
